# Hyprland 滚动布局

基于 Hyprland 0.56.2 的原生 scrolling 布局与 Quickshell。窗口沿水平方向滚动，每台显示器的工作区沿垂直方向排列。

窗口之间的实际间距为 4 像素，上下外边距为 4 像素。左右外边距与每个窗口的内侧间距同为 2 像素，避免滚动列对齐后在屏幕边缘露出相邻窗口的细条。三分之一、三分之二列宽预设使用足够精度，避免三个 `0.333` 列宽累计不足整屏而露出下一列。

上述边距依赖 Hyprland 对每个滚动列两侧都应用 `gaps_in`（hyprwm/Hyprland#16489，修复 #16422）。未包含该修复的 Hyprland 会省略首列左侧和末列右侧的内侧间距，屏幕边缘的间距随之变化。0.56.2 需要带该补丁的构建；升级或在其他机器部署前，先确认所用 Hyprland 已包含此修复。

鼠标悬停仍会切换焦点，但移入只露出一部分的窗口时不自动移动视角。`scrolling.follow_min_visible = 1.0` 抑制悬停跟随，`follow_focus = true` 保留键盘切换、条栏图标及概览选窗时的自动定位。

## 工作区规则

- 每台显示器独立维护纵向顺序。
- 最底部保留一个空工作区；放入窗口后自动追加新的空工作区。
- 当某台显示器没有窗口和命名工作区时，直接以当前工作区作为唯一空工作区；登录恢复或关闭最后一个窗口后无需先切换工作区。
- 中间的普通工作区变空、且不再处于活动状态时，从顺序中移除；命名工作区保留。
- 在一号工作区上方插入新工作区后，新工作区成为第一项，原有工作区依次下移。窗口不会因为编号变化而搬动。
- 顺序保存在 `~/.local/state/quickshell/user/scrolling-workspaces.json`，重启条栏后继续使用。

快捷键来源以改造前的本机备份 `~/Projects/hypr-scroll-design/backup-20261002-011435/.config/hypr/custom/keybinds.lua` 为准；上游默认配置没有包含用户全部自定义组合。前进／后退专用键搭配 Win、Ctrl＋Win、Win＋Shift、Win＋Alt 的 8 组操作在该备份中已经存在，均保留并适配动态工作区。Ctrl＋Win＋方向键、方括号和翻页键等也属于原有默认组合，不能把滚动布局的动作替换误认为新按键。

Win＋R 由 `custom/column_layout.lua` 联动调整当前一起查看的相邻列：`½＋½ → ⅔＋⅓ → ⅓＋⅔ → ⅓＋⅓＋⅓`。每组总宽为一屏，按 Hyprland 原生列信息识别，同列上下排列的窗口一起改变宽度。初次以包含焦点、在屏幕上占据最多可见面积的相邻列为组；连续切换保持这一组，三列档从相邻处补入一列。三列切回双列时确保焦点列仍在组内。工作区只有两列时跳过三列档，少于两列或当前焦点为浮动／全屏窗口时不调整。其他列保持原宽，原焦点和鼠标位置保留。重新加载配置可从当前宽度识别已有档位；手动改成其他比例后，再按 Win＋R 先恢复各半。

Win＋分号和 Win＋单引号恢复为单列宽度预设切换：分号执行 `colresize -conf`，单引号执行 `colresize +conf`，按 `⅓、½、⅔、1` 四档反向／正向循环，只调整焦点所在整列，并保留长按重复。Win＋R 继续负责多列联动。原有终端、侧栏、录屏、暂存工作区、鼠标拖动、缩放、媒体和工作区快捷键保留。滚轮保留 Win 切列、Ctrl＋Win 切工作区、Win＋Shift／Alt 发送窗口。此前单独要求删除的数字工作区组合和 Win＋Tab 仍保持禁用，Win 和 Win＋Space 仍是统一概览入口。备用 XFCE 保留自身默认快捷键和常用 Win 组合，只移除新增组合中的 Win＋T、Ctrl＋Win＋上下箭头。

视图中：上下选择工作区，左右或 Tab／Shift＋Tab 选择窗口，Enter 激活，Esc 关闭（点击卡片和搜索框以外的区域也会关闭），Insert 在选中工作区上方新增。拖动命中按卡片当前绘制的位置计算，动画与自动滚动期间逐帧刷新，松手时重新核对最终位置。执行插入时暂时将概览键盘焦点改为按需，原生换列完成后恢复独占焦点，避免布局命令因无法聚焦目标窗口而操作错误的列。拖动时源列收拢，目标列按被拖窗口的实际宽度预留空位，邻窗平滑避让。窗口带的占用宽度和滚动边界随避让同步动画，居中原点不会先跳到最终位置。松手后立即滑入预留位置，原生换列命令与动画并行执行；窗口、工作区和屏幕的新快照全部到齐后才恢复真实布局坐标，旧的在途查询不能提前结束交接。旧工作区被清空时，松手即预排它删除后的工作区顺序，让卡片直接移向最终位置，避免先向下吸附再向上折返。窗口卡片按地址统一维护，跨工作区时保留同一张卡片及其缩略图，从松手位置连续移入目标位置；原工作区被清空删除时，其余工作区和概览高度也平滑收缩。预留空位表示插入位置，不再显示竖线；放到窗口左半边会插在它前面，右半边则插在后面。既可在同一工作区重排，也可移到另一工作区的指定位置；空工作区在中央预留窗口位置；有窗口列时，相邻卡片让出对应列之间的完整窗口宽度。上下边缘自动滚动工作区，工作区卡片的左右边缘自动滚动窗口。拖动只移动所选窗口，上下堆叠的其他窗口保留；原列宽、最大化状态和鼠标位置保留，概览继续打开。中键关闭窗口。键盘选择跳过分组中被当前标签遮住的窗口。只有可见卡片中、位于可见范围内的缩略图实时更新，其余缩略图保留一帧画面。搜索框与概览始终处于同一个界面，输入文字后显示搜索结果，清空后回到概览。概览区域只保留纵向工作区和窗口缩略图，所有工作区卡片使用统一圆角，半径等于窗口圆角加内边距；概览高度按最多三个完整工作区、间距和内边距计算，第四个起滚动；概览宽度预算为屏幕可用逻辑宽度的 60%，每张工作区卡片按实际平铺列的尺寸、间距和内边距向下对齐到完整列，保持居中；横向边距固定在滚动视口外，刚好装满时不会额外滚动或露出下一列的一小条；上下和左右滚动视口使用固定的圆角矩形遮罩，卡片只显示一部分时仍按圆角裁切；沿用原版底色、阴影与居中应用图标；移除标题、工作区说明、窗口标题栏、工具按钮和详情弹窗。

拖放事务期间使用原生 `inhibit_scroll` 保持源、目标和原活动工作区的桌面视角。准备工作区时暂时阻止自动聚焦，换列完成并恢复原焦点后解除滚动抑制；原焦点窗口被移走时，恢复源工作区的原生候选焦点。后台临时切换工作区时使用零位移的工作区动画，恢复桌面上下文后立即还原配置，避免整组窗口被工作区渲染偏移向上推走、再滑回来；普通工作区切换、窗口换位和概览卡片动画保留。列宽未改变时不重复执行缩放，避免临时聚焦、换列和缩放把桌面先推到被拖窗口、再推回原处。概览表面显示期间暂时关闭软焦点跟随，阻止原生鼠标松开事件在后台插入开始前移动桌面视角；监听表面的打开和关闭，最后一个概览表面关闭后自动恢复原值，配置重载也会识别已经显示的概览。正常键盘导航和明确的窗口激活仍会跟随焦点滚动。

Scratch 打开时，拖放会明确选中普通工作区执行布局命令，完成后恢复每台屏幕原有的 Scratch 状态及动画；不会把普通窗口的换列命令送给暂存区。插入结果同时核对命令状态与新快照中的实际工作区、屏幕，失败会清除预留空位并返回真实位置。工作区行位置显式跟随顺序，横向居中直接跟随正在动画的宽度，避免行被删除、重建后保留旧偏移。截图从首次有效帧开始保留；异步抓取期间捕获失效时不覆盖旧截图。截图按窗口地址共享缓存，跨屏移动、关闭后在另一台屏幕重新打开概览时，新建卡片继续使用已有画面；关闭窗口才释放对应缓存。

窗口较少时，用工作区中较窄的整列宽度补齐预算内的空位；空工作区和只有浮动窗口的工作区按默认半屏列计算。全屏宽与半屏宽混合时按半屏列补齐，不因全屏列在左侧而缩短卡片；窗口过多时，边缘停在预算内最后一个完整列之后。单列本身超宽时保留完整宽度预算并允许滚动。窗口自身的比例保持不变，显示器缩放和旋转由可用逻辑尺寸统一处理。

搜索时，名称、应用 ID、通用名称或关键词明确匹配的应用最多优先显示 3 项，接着显示联网搜索、执行命令和有效的数学结果，再显示弱匹配应用；普通模式的应用候选最多 8 项。描述、分类和命令路径产生的模糊匹配不会挤掉这些快捷结果。明确的计算式、函数或单位换算会把数学结果置顶，计算失败不会沿用上一次的答案。`? 搜索词`、`$ 命令`、`> 应用名`、`= 算式` 分别只显示对应类别，应用专用模式保留全部匹配；剪贴板、表情和 `/` 操作前缀继续可用。

触摸板：三指横滑时窗口跟随手指移动（`custom/column_swipe.lua`）：慢慢拖到位再松手，停在画面中最近的停靠点（某列居中或两侧贴边），吸附移动不超过八分之一屏；快速甩动按速度翻页，只停在贴边位置；首尾两端不留空白，划得过短会回到原位；原焦点窗口仍完整可见时保留焦点，鼠标位置不变。快甩阈值为 `flick_speed`（屏／秒），可用 `hyprctl repl 'print(require("custom.column_swipe").describe())'` 查看上次松手速度以便调整；三指上滑进入下方工作区、下滑进入上方工作区；四指上下／左右滑动拖动当前窗口（平铺窗口上下调整同列顺序、左右移入相邻列，浮动窗口跟随手势移动）；三指捏合切换全屏，四指捏合切换窗口视图。Win＋Shift＋左右通过交换相邻列来移动整列，最左列向左、最右列向右时保持原位，不循环换列。

三指横滑支持平铺窗口的 Win＋D 最大化：窗口仍作为整屏宽的列参与滚动，滑动不会取消其最大化状态。Win＋F 真正全屏时不响应横滑，浮动最大化窗口也不会滚动背后的平铺窗口。拖动期间保留焦点，避免原生 `layoutmsg move` 的硬焦点定位把整屏宽的列反复拉回；抬手后恢复正常焦点行为并沿用原有的停靠动画。小于半像素的滑动增量也会累计，避免慢速拖动丢失位移。

## 条栏

各屏幕的活动工作区和焦点读取 Hyprland 的当前快照，不再用 Quickshell 缓存覆盖。快照服务直接监听可重连的事件连接，断开后每 500 毫秒重连，并在断开期间每秒刷新。概览打开时固定所属屏幕：Win 使用当前焦点屏幕，右键窗口条使用该条所在屏幕；拖动引起的临时焦点变化不会让概览跳到另一块屏幕。开始拖动窗口卡片后，其余屏幕临时显示各自的工作区，按屏幕实际位置直接拖过去，可插入已有工作区的任意列间，也可放到新空工作区。其他屏幕不抢键盘或鼠标抓取，原来的搜索输入留在打开概览的屏幕；松手后立即吸附，后台跨屏插入完成才交接给目标卡片，临时概览随之收起。平铺窗口按目标屏幕的可用逻辑宽高调整预览，保持列宽比例；浮动窗口保留像素尺寸。松手时同时预测两边的动态工作区顺序，避免空的新工作区被误归到原屏幕。

布局变化通过 Hyprland 自定义 IPC 事件 `ii:layoutChanged` 通知条栏立即刷新。通知使用 `hl.dsp.event`；不要在换列、合并或调宽的按键回调内使用 `hl.dsp.global`，它会请求松键回调，导致整个布局动作在按下和松开时各执行一次。

切换工作区时，窗口条按各显示器的动态纵向顺序上下滚动：进入下方工作区时旧图标向上退出、新图标从下方进入，反向切换则相反；跳过多项时经过中间工作区。动画沿用 200 毫秒缓动，连续切换从当前进度接着移动；空工作区退场后再清理对应图标行，避免动态删除截断动画。暂存区的图标从当前工作区相邻的一行滑入，关闭时反向滑回；退场结束后才移除这行，连续开关从当前进度接着动画。

窗口条沿用原版 `Workspaces.qml` 的分层：所有窗口连成半透明占用胶囊，焦点使用独立的主色胶囊，悬停／按压再叠加交互层。焦点胶囊复用 `AnimatedTabIndexPair`，两端分别用 100／300 毫秒移动，先拉长再收拢；切换焦点时，图标大小和透明度也平滑变化。图标继续用 `StyledImage`，焦点图标 19 像素，其余按 0.8 倍缩小。窗口条溢出时，占用底层保持视口内的完整圆角；另一显示器的焦点标记更淡。

新增或关闭窗口时，占用胶囊的宽度使用与图标移动相同的 200 毫秒缓动，位置直接由动画中的宽度居中，避免位置动画再追赶宽度而产生延迟。交换窗口或列后，窗口条保留各窗口对应的图标，并用与横向滚动一致的 200 毫秒缓动移动到新位置。排序模型只保存窗口地址，图标等元数据单独按地址读取；避免 `ScriptModel` 在元数据和顺序同时变化时批量替换数据，漏掉移动事件及其动画。

原来的十个工作区点替换为窗口条：图标总长度不超过条带时整组居中；超出时，让焦点图标尽量居中，并将滚动位置限制在两端，避免条带边缘留空。随左右切换平滑滚动，超出条带范围的部分裁切。点击图标聚焦窗口，鼠标保持在条栏原位置；滚轮每格切换一列（触控板按同样的距离累积）；暂存区打开时窗口条显示暂存区的窗口；没有键盘焦点的显示器用较淡的底色标出它最近聚焦的窗口；交换、合并、拆分、调整宽度和居中列后，窗口顺序立即刷新（这些操作本身不产生 Hyprland 事件，由快捷键通知 Quickshell）；右键打开／关闭概览；与原版一样不设独立概览按钮，窗口图标使用完整条带。移除两侧箭头、窗口计数和窗口条的悬浮详情。图标使用 StyledImage，以同步加载避免热重载后的错误图标。资源与媒体位于左侧，时钟与工具按钮位于右侧；原有外侧标题和托盘保留。
