# Hyprland 滚动布局

基于 Hyprland 0.56.2 的原生 scrolling 布局与 Quickshell。窗口沿水平方向滚动，每台显示器的工作区沿垂直方向排列。

窗口之间的实际间距为 4 像素，上下外边距为 4 像素。左右外边距与每个窗口的内侧间距同为 2 像素，避免滚动列对齐后在屏幕边缘露出相邻窗口的细条。三分之一、三分之二列宽预设使用足够精度，避免三个 `0.333` 列宽累计不足整屏而露出下一列。

上述边距依赖 Hyprland 对每个滚动列两侧都应用 `gaps_in`（hyprwm/Hyprland#16489，修复 #16422）。未包含该修复的 Hyprland 会省略首列左侧和末列右侧的内侧间距，屏幕边缘的间距随之变化。0.56.2 需要带该补丁的构建；升级或在其他机器部署前，先确认所用 Hyprland 已包含此修复。

鼠标悬停仍会切换焦点，但移入只露出一部分的窗口时不自动移动视角。`scrolling.follow_min_visible = 1.0` 抑制悬停跟随，`follow_focus = true` 保留键盘切换、条栏图标及概览选窗时的自动定位。

## 工作区规则

- 每台显示器独立维护纵向顺序。
- 最底部保留一个空工作区；放入窗口后自动追加新的空工作区。
- 当某台显示器没有窗口和命名工作区时，直接以当前工作区作为唯一空工作区；登录恢复或关闭最后一个窗口后无需先切换工作区。
- 中间的普通工作区变空、且不再处于活动状态时，从顺序中移除；命名工作区保留。
- 在一号工作区上方插入新工作区后，新工作区成为第一项，原有工作区依次下移。窗口不会因为编号变化而搬动。
- 顺序保存在 `~/.local/state/quickshell/user/scrolling-workspaces.json`，重启条栏后继续使用。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| Win / Win＋Space | 打开／关闭同一个概览与搜索界面，可使用中文输入法 |
| Win＋V / Win＋句号 | 剪贴板 / 表情搜索 |
| Win＋Enter / Win＋T / Ctrl＋Alt＋T | 打开终端 |
| Win＋A / Win＋B / Win＋O | 打开／关闭左侧栏 |
| Win＋左右箭头 / Win＋左右方括号 | 聚焦相邻列 |
| Win＋上下箭头 | 聚焦同列的上下窗口 |
| Win＋Shift＋左右箭头 | 向左／右移动整列 |
| Win＋Shift＋上下箭头 | 在同一列中向上／下移动窗口 |
| Win＋Alt＋左右箭头 | 合并窗口到相邻列，或从同列分离窗口 |
| Win＋R | 联动切换：各半 → 左宽右窄 → 左窄右宽 → 三窄列 |
| Win＋分号 / Win＋单引号 | 单独调整当前列到上一档 / 下一档宽度，可长按连续调整 |
| Ctrl＋Win＋C | 将当前列居中 |
| Win＋Shift＋PgUp／PgDn | 将窗口送到上／下工作区并跟随 |
| Win＋Alt＋PgUp／PgDn / Ctrl＋Win＋Shift＋左右箭头 | 将窗口送到上／下工作区并跟随（原有组合） |
| Win＋PgUp／PgDn | 切换上／下工作区 |
| Ctrl＋Win＋方向键／左右方括号／PgUp／PgDn | 切换相邻工作区（原有组合） |
| Win／Ctrl＋Win 搭配 XF86Back／XF86Forward | 切换相邻工作区（用户原有组合） |
| Win＋Shift／Win＋Alt 搭配 XF86Back／XF86Forward | 将窗口送到相邻工作区并跟随（用户原有组合） |
| Ctrl＋Win＋Shift＋上下箭头 | 将当前工作区向上／下重排 |
| Ctrl＋Win＋Insert | 在当前工作区上方插入并进入新工作区 |
| Ctrl＋Win＋Alt＋方向键 | 切换显示器 |
| Win＋Alt＋Shift＋方向键 | 将当前窗口移到该方向屏幕的当前工作区，并跟随焦点 |

快捷键来源以改造前的本机备份 `~/Projects/hypr-scroll-design/backup-20261002-011435/.config/hypr/custom/keybinds.lua` 为准；上游默认配置没有包含用户全部自定义组合。前进／后退专用键搭配 Win、Ctrl＋Win、Win＋Shift、Win＋Alt 的 8 组操作在该备份中已经存在，均保留并适配动态工作区。Ctrl＋Win＋方向键、方括号和翻页键等也属于原有默认组合，不能把滚动布局的动作替换误认为新按键。

Win＋R 由 `custom/column_layout.lua` 联动调整当前一起查看的相邻列：`½＋½ → ⅔＋⅓ → ⅓＋⅔ → ⅓＋⅓＋⅓`。每组总宽为一屏，按 Hyprland 原生列信息识别，同列上下排列的窗口一起改变宽度。初次以包含焦点、在屏幕上占据最多可见面积的相邻列为组；连续切换保持这一组，三列档从相邻处补入一列。三列切回双列时确保焦点列仍在组内。工作区只有两列时跳过三列档，少于两列或当前焦点为浮动／全屏窗口时不调整。其他列保持原宽，原焦点和鼠标位置保留。重新加载配置可从当前宽度识别已有档位；手动改成其他比例后，再按 Win＋R 先恢复各半。

Win＋分号和 Win＋单引号恢复为单列宽度预设切换：分号执行 `colresize -conf`，单引号执行 `colresize +conf`，按 `⅓、½、⅔、1` 四档反向／正向循环，只调整焦点所在整列，并保留长按重复。Win＋R 继续负责多列联动。原有终端、侧栏、录屏、暂存工作区、鼠标拖动、缩放、媒体和工作区快捷键保留。滚轮保留 Win 切列、Ctrl＋Win 切工作区、Win＋Shift／Alt 发送窗口。此前单独要求删除的数字工作区组合和 Win＋Tab 仍保持禁用，Win 和 Win＋Space 仍是统一概览入口。备用 XFCE 保留自身默认快捷键和常用 Win 组合，只移除新增组合中的 Win＋T、Ctrl＋Win＋上下箭头。

视图中：上下选择工作区，左右或 Tab／Shift＋Tab 选择窗口，Enter 激活，Esc 关闭（点击卡片和搜索框以外的区域也会关闭），Insert 在选中工作区上方新增。可拖动窗口到其他工作区，中键关闭窗口。搜索框与概览始终处于同一个界面，输入文字后显示搜索结果，清空后回到概览。概览区域只保留纵向工作区和窗口缩略图，所有工作区卡片使用统一圆角，半径等于窗口圆角加内边距；概览高度按最多三个完整工作区、间距和内边距计算，第四个起滚动；概览宽度预算为屏幕可用逻辑宽度的 60%，每张工作区卡片按实际平铺列的尺寸、间距和内边距向下对齐到完整列，保持居中；横向边距固定在滚动视口外，刚好装满时不会额外滚动或露出下一列的一小条；上下和左右滚动视口使用固定的圆角矩形遮罩，卡片只显示一部分时仍按圆角裁切；沿用原版底色、阴影与居中应用图标；移除标题、工作区说明、窗口标题栏、工具按钮和详情弹窗。

窗口较少时，用工作区中较窄的整列宽度补齐预算内的空位；空工作区和只有浮动窗口的工作区按默认半屏列计算。全屏宽与半屏宽混合时按半屏列补齐，不因全屏列在左侧而缩短卡片；窗口过多时，边缘停在预算内最后一个完整列之后。单列本身超宽时保留完整宽度预算并允许滚动。窗口自身的比例保持不变，显示器缩放和旋转由可用逻辑尺寸统一处理。

搜索时，名称、应用 ID、通用名称或关键词明确匹配的应用最多优先显示 3 项，接着显示联网搜索、执行命令和有效的数学结果，再显示弱匹配应用；普通模式的应用候选最多 8 项。描述、分类和命令路径产生的模糊匹配不会挤掉这些快捷结果。明确的计算式、函数或单位换算会把数学结果置顶，计算失败不会沿用上一次的答案。`? 搜索词`、`$ 命令`、`> 应用名`、`= 算式` 分别只显示对应类别，应用专用模式保留全部匹配；剪贴板、表情和 `/` 操作前缀继续可用。

触摸板：三指横滑时窗口跟随手指移动（`custom/column_swipe.lua`）：慢慢拖到位再松手，停在画面中最近的停靠点（某列居中或两侧贴边），吸附移动不超过八分之一屏；快速甩动按速度翻页，只停在贴边位置；首尾两端不留空白，划得过短会回到原位；原焦点窗口仍完整可见时保留焦点，鼠标位置不变。快甩阈值为 `flick_speed`（屏／秒），可用 `hyprctl repl 'print(require("custom.column_swipe").describe())'` 查看上次松手速度以便调整；三指上滑进入下方工作区、下滑进入上方工作区；四指上下／左右滑动拖动当前窗口（平铺窗口上下调整同列顺序、左右移入相邻列，浮动窗口跟随手势移动）；三指捏合切换全屏，四指捏合切换窗口视图。Win＋Shift＋左右通过交换相邻列来移动整列，最左列向左、最右列向右时保持原位，不循环换列。

## 条栏

原来的十个工作区点替换为窗口条：图标总长度不超过条带时整组居中；超出时，让焦点图标尽量居中，并将滚动位置限制在两端，避免条带边缘留空。随左右切换平滑滚动，超出条带范围的部分裁切。点击图标聚焦窗口，鼠标保持在条栏原位置；滚轮每格切换一列（触控板按同样的距离累积），右键打开／关闭概览；与原版一样不设独立概览按钮，窗口图标使用完整条带。移除两侧箭头、窗口计数和窗口条的悬浮详情。图标使用 StyledImage，以同步加载避免热重载后的错误图标。资源与媒体位于左侧，时钟与工具按钮位于右侧；原有外侧标题和托盘保留。
