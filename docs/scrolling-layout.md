# Hyprland 滚动布局

基于 Hyprland 0.56.2 的原生 scrolling 布局与 Quickshell。窗口沿水平方向滚动，每台显示器的工作区沿垂直方向排列。

## 工作区规则

- 每台显示器独立维护纵向顺序。
- 最底部保留一个空工作区；放入窗口后自动追加新的空工作区。
- 中间的普通工作区变空、且不再处于活动状态时，从顺序中移除；命名工作区保留。
- 在一号工作区上方插入新工作区后，新工作区成为第一项，原有工作区依次下移。窗口不会因为编号变化而搬动。
- 顺序保存在 `~/.local/state/quickshell/user/scrolling-workspaces.json`，重启条栏后继续使用。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| Win / Win＋Space | 打开／关闭同一个概览与搜索界面，可使用中文输入法 |
| Win＋V / Win＋句号 | 剪贴板 / 表情搜索 |
| Win＋左右箭头 | 聚焦相邻列 |
| Win＋上下箭头 | 聚焦同列的上下窗口 |
| Win＋Shift＋左右箭头 | 向左／右移动整列 |
| Win＋Shift＋上下箭头 | 在同一列中向上／下移动窗口 |
| Win＋Alt＋左右箭头 | 合并窗口到相邻列，或从同列分离窗口 |
| Win＋分号 / Win＋单引号 | 前一个／后一个列宽预设 |
| Win＋R | 下一个列宽预设 |
| Ctrl＋Win＋C | 将当前列居中 |
| Win＋Shift＋PgUp／PgDn | 将窗口送到上／下工作区并跟随 |
| Ctrl＋Win＋Shift＋左右箭头 | 将窗口送到上／下工作区并跟随 |
| Ctrl＋Win＋上下箭头 | 切换上／下工作区 |
| Ctrl＋Win＋Shift＋上下箭头 | 将当前工作区向上／下重排 |
| Ctrl＋Win＋Insert | 在当前工作区上方插入并进入新工作区 |
| Ctrl＋Win＋Alt＋方向键 | 切换显示器 |
| Win＋Alt＋Shift＋方向键 | 将当前窗口移到该方向屏幕的当前工作区，并跟随焦点 |

视图中：上下选择工作区，左右或 Tab 选择窗口，Enter 激活，Esc 关闭，Insert 在选中工作区上方新增。可拖动窗口到其他工作区，中键关闭窗口。搜索框与概览始终处于同一个界面，输入文字后显示搜索结果，清空后回到概览。概览区域只保留纵向工作区和窗口缩略图，所有工作区卡片使用统一圆角，半径等于窗口圆角加内边距；概览高度按最多三个完整工作区、间距和内边距计算，第四个起滚动；概览宽度预算为屏幕可用逻辑宽度的 60%，每张工作区卡片按实际平铺列的尺寸、间距和内边距向下对齐到完整列，保持居中；横向边距固定在滚动视口外，刚好装满时不会额外滚动或露出下一列的一小条；上下和左右滚动视口使用固定的圆角矩形遮罩，卡片只显示一部分时仍按圆角裁切；沿用原版底色、阴影与居中应用图标；移除标题、工作区说明、窗口标题栏、工具按钮和详情弹窗。

窗口较少时，用工作区中较窄的整列宽度补齐预算内的空位；空工作区和只有浮动窗口的工作区按默认半屏列计算。全屏宽与半屏宽混合时按半屏列补齐，不因全屏列在左侧而缩短卡片；窗口过多时，边缘停在预算内最后一个完整列之后。单列本身超宽时保留完整宽度预算并允许滚动。窗口自身的比例保持不变，显示器缩放和旋转由可用逻辑尺寸统一处理。

触摸板：三指横滑滚动窗口视野，三指上滑进入下方工作区、下滑进入上方工作区；四指上下／左右滑动拖动当前窗口（平铺窗口上下调整同列顺序、左右移入相邻列，浮动窗口跟随手势移动）；三指捏合切换全屏，四指捏合切换窗口视图。Win＋Shift＋左右通过交换相邻列来移动整列，最左列向左、最右列向右时保持原位，不循环换列。

## 条栏

原来的十个工作区点替换为窗口条：图标总长度不超过条带时整组居中；超出时，让焦点图标尽量居中，并将滚动位置限制在两端，避免条带边缘留空。随左右切换平滑滚动，超出条带范围的部分裁切。点击图标聚焦窗口，鼠标保持在条栏原位置；滚轮切换窗口列，右键打开／关闭概览；与原版一样不设独立概览按钮，窗口图标使用完整条带。移除两侧箭头、窗口计数和窗口条的悬浮详情。图标使用 StyledImage，以同步加载避免热重载后的错误图标。资源与媒体位于左侧，时钟与工具按钮位于右侧；原有外侧标题和托盘保留。
